# 面试官角色定位

## 核心定位

:::
面试官是公司人才质量的**“第一守门人”**，通过专业能力评估，素质能力评估与文化适配判断，确保候选人匹配岗位需求；同时向候选人传递公司价值观，构建积极、有吸引力的雇主品牌形象。
:::

## 为什么要重视面试工作及面试官培训？

1.  **招聘并非仅仅是人力资源的工作**
    
    ++**选拔人是比培养人更重要的一件事。**++招聘的本质是满足业务发展，组织用人需求，其最终目的在于推动业务成果的达成。因此，招聘不仅是人力资源部门的职责，更是业务目标实现的关键环节。每位团队负责人都必须在人才筛选环节投入足够精力。
    
2.  **精准选才优于后期补救**
    
    在组织快速发展周期内，与时间赛跑，成功招聘到合适（专业有经验、素质文化匹配）的人选，其重要性远超入职后的培养人才。
    
3.  **面试官即公司形象代言人**
    

面试官是企业在人才市场上的“第一形象代表”。面试官所展现的专业素养，直接反映了公司的整体形象和专业水准。

# 面试标准流程

:::
**各角色应在整体面试流程中统一标准，各司其职，做好承接，共同完成人才甄别工作**

**终面原则采用线下形式****：**所有终面环节原则上必须采用线下面对面形式进行。此举旨在确保与候选人进行最充分、最深入的互动与评估，避免依赖AI等面试技术工具可能对评估质量产生的影响。

++**例外情况说明：**++++仅在极特殊情况下（如候选人存在不可克服的地理位置限制或其他不可抗力因素无法到面），且经招聘负责人及最终录用决策者++++**一致确认**++++通过线上面试已能全面、准确完成所有关键评估项时，方可酌情采用线上形式完成终面。此例外情况需提前报备并获得正式批准。++

**候选人体验优先：**单次到访完成多轮评估，确保候选人仅需到场一次；同一场次可安排多位面试官背靠背协同评估。

**评估矩阵化管理：**面试官按角色定位进行分工（参考《核心职责与能力要求》），关键能力项需至少2名面试官独立验证（如技术深度+文化适配）
:::

## 需求提报

:::
**核心目标：**精准定义岗位所需人才标准。

**核心动作**：明确岗位需求定位，构建岗位人才画像，完成需求提报

++核心角色：业务负责人（主导）/HRBP（协作）++
:::

### [Done]  执行要点：

1.  **深度沟通，明确需求：** 业务负责人需与HRBP深入沟通，明确待招岗位在团队/组织中的核心定位、关键职责、需求产生的原因，以及面临的挑战，输出标准《岗位JD》；
    
2.  **使用标准工具，输出人才画像：**
    
    1.  ++**标准模版：**++[请至钉钉文档查看附件《03 岗位人才画像模版》。](https://alidocs.dingtalk.com/i/nodes/Gl6Pm2Db8De06Pg6UqRo974eWxLq0Ee4?corpId=ding56ed6f95485bd2bc35c2f4657eb6378f&doc_type=wiki_doc&iframeQuery=anchorId%3DX02mcok7r11jtws9hjk0k&utm_medium=im_card&utm_scene=team_space&utm_source=im)
        
    2.  **聚焦关键能力：** 
        
        1.  清晰阐述该岗位的**工作重点及关键挑战**；
            
        2.  识别并提炼该岗位成功所必需的**任职资格条件**（如年龄、学历、工作经历、专业资格等）
            
        3.  勾选该岗位必须得**专业能力**和**素质能力，**及对应的表现（参考[《01 面试官手册（260304修订版）》](https://alidocs.dingtalk.com/i/nodes/Gl6Pm2Db8De06Pg6UqRo974eWxLq0Ee4?utm_scene=team_space&iframeQuery=anchorId%3Duu_mcnce1r70io8qllpjqw)）。
            
    3.  **量化期望：** 
        
        1.  尽可能对关键职责和能力要求进行量化描述（如“管理X人团队”、“主导过预算规模Y的项目”、“将Z指标提升N%”），
            
        2.  给出评分标准（如5分对应表现，1分对应表现）；
            
    4.  **人无完人，明确需求优先级：** 
        
        1.  区分岗位要求优先级——“必备项”和“加分项”；
            
        2.  明确需求排期优先级——P0(非常紧急-需要重点支持)/P1（没有P0紧急）/P2(可以缓慢推进)
            
3.  **招聘需求提提报**
    
    1.  至moka系统完成需求提报，提报流程参考：[《业务方【招聘需求提报】操作说明》](https://alidocs.dingtalk.com/i/nodes/ydxXB52LJqeL6G26Uv0rdq1YJqjMp697?doc_type=wiki_doc)
        
4.  **同步《岗位JD》与《人才画像》至招聘面试官，对齐招聘需求**

## 简历筛选

:::
**核心目标：** 高效识别与岗位人才画像匹配的候选人。

**核心动作：** **基于画像内容，快速、客观的完成简历初评与筛选**。

++核心角色： 招聘面试官 / 业务负责人/业务组长（部分）++
:::

### [Done]  执行要点：

1.  **紧扣画像标准做筛选：** 以该岗位的《人才画像》中定义的“必备勾选项”作为第一轮筛选的核心依据。
    
    1.  **关键词匹配初筛：** 快速扫描简历，寻找与岗位++**核心职责、所需技能、经验年限、行业背景**++等相关的关键词，进行初步筛选后进入下一环节。
        
    2.  **任职资格核查：** 严格检查++**学历/履历/项目经验**++等是否符合要求；关注前置简历++**真实性筛查**++。
        
    3.  **专业能力初评：** 关注候选人在过往经历中承担的++**具体职责、主导的项目、达成的量化成果，获得的具体成就**++**，**评估其与目标岗位的关联性和能力体现。
        
    4.  **素质能力初评****：** 通过简历中的++**项目描述、职责范围、晋升路径、社团活动（应届生）**++等信息，初步识别并判断其核心素质能力及文化价值观适配。
        
2.  **筛选结果反馈**
    
    1.  **高效处理与记录：** 充分使用moka系统，制定清晰的筛选流程（如分轮次筛选），并记录筛选理由（特别是淘汰原因），确保过程可追溯、公平高效。
        
    2.  **及时同步信息及沟通：** 将初步筛选通过的候选人简历及评估提交，进入下一环节；对明显不符的候选人需及时关闭流程并同步流程中的相关人员。
        
3.  **面试流程规划（业务负责人）：**
    
    1.  **面试官识别及流程规划：**识别本团队内各位面试官能力，将初筛通过的候选人简历进行合理分派，并做好初试/复试/终试各环节流程安排。
        
    2.  **画像同步&标准统一**：将清晰的人才画像同步至各轮面试官，++协调各轮面试标准及考察重点。++
        

## 面试前准备

:::
**核心目标：** 做好准备工作，确保面试过程专业、聚焦及高效。

**核心动作：** 认真研读简历，基于岗位画像，系统规划面试内容与流程。

++核心角色： 所有面试官++
:::

### [Done]  执行要点：

1.  **明确岗位需求与画像**
    
    1.  熟悉《岗位JD》、《人才画像》，明确待面岗位的核心职责、专业能力要求、素质能力要求；明确该岗位的“必备项”和“加分项”；
        
2.  **简历深度研读：** 仔细阅读候选人简历，对照该岗位的需求与画像，识别简历与画像的匹配/差距点及潜在疑点，并做好标记。
    
3.  **面试内容规划：**
    
    1.  **明确考察维度与权重：** 
        
        1.  参考【[《01 面试官手册（260304修订版）》](https://alidocs.dingtalk.com/i/nodes/Gl6Pm2Db8De06Pg6UqRo974eWxLq0Ee4?utm_scene=team_space&iframeQuery=anchorId%3Duu_mctyx5m7rtopnhabyyd)】中自己所处的面试环节及核心职责，与业务负责人讨论并确定本次面试++**重点考察的能力项**++
            
        2.  通常++**聚焦2-4项核心能力**++（如初面面试官需着重考察：工具使用、代码能力测试；项目经验、业绩结果等；沟通表达/礼仪），并明确各维度在本次面试中的相对权重。
            
    2.  **设计结构化面试问题：**基于本次面试的重点考察的核心能力项（专业能力&素质能力），提前规划有针对性的面试问题
        

*   **行为事件问题：**
    
*   基于核心能力维度，设计具体的行为事件问题，评估过往经验。
    
*   如：“请分享一个你处理过最具挑战性的项目冲突的实例？”
    
*   **情景问题：**
    
*   模拟工作场景，考察候选人应对能力。
    
*   如：“如果遇到...情况，你会如何处理？”
    
*   **技术/专业问题：**
    
*   针对岗位需求设计技术解决方案或案例分析。
    
*   如：“请设计一个……的方案，要求达成……的目标
    
*   **文化适配问题：**
    
*   了解候选人价值观与公司文化的匹配度。
    
*   如：”当工作中团队出现了……样的情况，你如何理解/处理？“
    
*   **疑点排查：**
    
*   基于简历或考察过程中的潜在疑点进行深入追问。
    
    1.  **统一评分标准：**对照该岗位的《人才画像》， 为关键问题预设理想回答要点或评分锚点。（如：在该维度1分表现应是什么，2分表现应是什么）
        
    2.  [警告]**分配面试官角色与问题（业务负责人/招聘面试官）：** 多轮/多人面试需明确各面试官的提问重点和考察维度，++**避免重复提问**++。
        

1.  **其他准备（招聘面试官）：**
    
    1.  **沟通面试流程与时间：** 向候选人清晰说明面试流程、预计时长、面试官构成，营造专业、尊重的第一印象。
        
    2.  **准备面试环境与材料：** 确保面试环境（线上/线下）安静、专业；根据需求准备好简历、岗位描述、人才画像、面试问题清单、评分表等。

**核心动作：** 运用专业沟通技巧，精准评估候选人能力与潜力。

++核心角色： 所有面试官++

### [回收标志]  面试规划和时间控制（参考）

| **流程** | **时长** |
| --- | --- |
| **面试开场与基本了解**（建立信任） |  |
| 开场白与面试官自我介绍 | 1分钟 |
| 候选人自我介绍或关键经验询问 | ++5分钟++ |
| **提问与倾听**（事先计划的现场面试问题） |  |
| 专业能力评估（2-3项） | 15分钟 |
| 素质能力评估（2-3项） | 10分钟 |
| 简历疑点排查 | 5分钟 |
| 动机挖掘（离职和入职） | 5分钟 |
| **面谈结束** |  |
| 提供信息与答疑 | 3分钟 |
| 结束感谢 | 1分钟 |
| **总计** | **45分钟** |

### [Done]  执行要点：

1.  **面试开场与基本了解：**
    
    *   准时开始，友好问候，简要自我介绍。
        
    *   清晰说明面试流程、目的和时长。
        
    *   营造轻松、开放、平等的对话氛围，缓解候选人紧张情绪。
        
2.  **有效提问——结构化面试问题：**
    
    *   **专业能力评估：**针对预设的核心能力问题，聚焦行为事例，运用++**STAR原则**++（Situation情景, Task任务, Action行动, Result结果）进行深度提问，获取具体、完整的行为事例。
        
    *   **素质能力评估：**将++**能力项转化成行为，再转化成问题**++，再通过使用BEI行为事件访谈法进行提问
        
    *   **深入追问&疑点排查：** 对模糊、笼统的回答（如“我们团队合作得很好”）进行层层追问（如“你具体负责哪部分？”、“当时遇到了什么困难？”、“你采取了什么具体行动？”、“最终结果如何？”）。
        
    *   **真实动机挖掘：**包括离职动机（预判雇佣风险），入职动机（预判稳定性与文化适配）

    *   **观察非语言信号**
        
        *   肢体语言：是否放松、眼神交流、手势是否自然。
            
        *   语言表达：逻辑性、条理性、是否夸大或回避问题。
            
        *   情绪反应：面对压力或挑战性问题时的表现。
            
4.  **提供信息与答疑：**
    
    *   清晰介绍公司、团队、岗位的具体情况和发展机会。

**面试礼仪很重要：**

准时开始，准时结束；

如果面试刚开始就发现不合适，但也请尽可能保证面试流程的完整性；

避免容易被误解为歧视的问题（如婚姻、宗教等）

**控制节奏与时间：** 

合理分配时间给不同问题，确保核心能力点得到充分考察；

适时引导话题，避免过度发散。

**警惕面试目标跑偏：**

不要使用偏题怪题，或者纠缠于候选人未能正确作答的某个问题；

面试不是吵架，不是为了压倒对方或者证明自己

**不要被候选人牵着鼻子走：**

允许候选人提问，但始终记住面试主题，避免角色反转；

有时间观念，礼貌的打断候选人。

**保持中立与客观：**

避免引导性问题或暗示期望答案；

不要当场给出面试结论，或表现出明显倾向；禁止与候选人现场谈钱

对每位候选人使用相同核心问题框架，保证公平性

++**注意保密：**++

++**不要泄露我司商业机密！避免被面试！避免被套取商业信息！**++

++**禁止询问或透露薪资等敏感信息。（可跟候选人表达后续由招聘面试官统一沟通）**++

## 面评撰写

:::
**核心目标：** 清晰、准确、客观地记录面试评估过程与结论，为决策提供依据，并建立人才档案。

**核心动作：** 基于评估结论，规范、及时地完成面试评价报告。

++核心角色：所有面试官++
:::

### [Done]  执行要点：

1.  **及时性：** 在面试结束或评估决策达成后**24小时内**完成撰写，确保信息新鲜准确。
    
2.  **使用标准模板：** 严格使用公司统一的moka《面试评价》系统，确保信息结构化、关键字段完整。
    
3.  **标准模版包括能力评分、综合反馈、面试结果三部分：**
    
    *   **能力评分：1）**面试官应按照候选人面试岗位级别对应的能力标准进行评估与打分（如面试初级岗位，则按初级能力标准评估其业务能力），**详见截图中红色框示意**。**2）**严格参照++**《人才画像》**++中的各项维度评分标准进行，并将STAR事例中的++**具体行为/评分依据**++填写至打分后的弹窗中。

4.  **内容要求：**
    
    *   **客观具体：** 
        
        *   描述候选人适配的表现时，**必须****引用面试中观察到的具体行为、事例（STAR）和语言**。而非主观感受或直觉。区分“事实”与“推断”。
            
        *   避免使用模糊、主观、笼统的形容词（如“沟通能力好”、“技术不错”）。

    *   **突出亮点：** 清晰总结候选人的核心优势（匹配点）和主要不足/风险点（差距点）。
        
    *   **明确结论与建议：** 清晰给出最终的评估结论（强烈推荐/推荐/待定/不推荐）及具体、可操作的建议（如“建议录用”、“需加面考察XX能力”、“需重点背调XX经历”）。

## 评估与决策

:::
**核心目标：**  基于客观证据与统一标准，做出准确、一致的录用决策。

**核心动作：**  **对照岗位画像，综合评估候选人表现，达成共识性决策。**

++核心角色： 所有面试官++
:::

### [Done]  执行要点：

1.  **及时回顾与独立评估：** 在面试结束后尽快（最好当日）回顾面试笔记和记录。**严格对照《人才画像模版》中的各项标准（专业能力&素质能力）**，对候选人在每个核心维度的表现进行独立、客观的评估打分或评级。
    
2.  **聚焦行为证据：** 评估必须基于面试中收集到的**具体行为事例（STAR）** 和**客观事实**，而非主观感受或直觉。区分“事实”与“推断”。
    
3.  **团队协作评估：** 
    
    1.  如有多人/多轮面试，需先独立评估，避免“群体思维”，拥有独立观点。
        
    2.  所有面试结束后，需汇总所有面试官的意见和记录，并讨论分歧，最终达成一致。
        
4.  **明确决策结论：**最终由招聘面试官整合各方反馈，提炼关键信息，与业务负责人确认最终录用决定，以及推进节奏。（**强烈推荐（尽快推进）**、**推荐（正常推进）**、**待定（保温再看看）**、**不推荐（pass）**。
    
5.  **风险与合规性审视：**招聘面试官负责安排后续动作：谈薪、OFFER，背调等。过程中需审视决策过程是否符合公司政策、法律法规，评估是否有潜在用工风险。
    

:::
**录用决策的核心原则：**++**永远去录用团队中位线水平以上的人！**++

即使团队当下特别缺人，也不要放宽招聘标准，或寄希望于试用期再做筛选；

录用平庸的人可能会出现的影响：

平庸的人做平庸的决策 

团队本身优秀的年轻人离开 

平庸的人接着招平庸的人 

你要不断给平庸的人擦屁股

++**"每个事情都有机会成本，我们不如花时间投入到寻找更优秀的候选人身上"**++
:::

# 面试官培养及管理

:::
**目标**：通过系统性实践与反馈，将培训知识转化为实战能力，确保每位面试官具备独立、专业、合规的招聘能力。
:::

## 面试官人才管理

:::
**公司对面试官实行统一管理，所有面试官均须经过选拔、提报与培训流程，纳入【面试官人才库】后，方可被分派面试任务。**

**未入库员工一律不得参与面试。**
:::

## 面试官选拔

*   **面试官选拔由****各团队业务负责人****进行。**
    
*   **选拔条件：**
    
    1.  深入理解业务及团队人才需求；
        
    2.  具备良好的沟通、判断与决策能力；
        
    3.  工作态度严谨，能客观公正地评估候选人；
        
    4.  有意愿投入时间参与面试及相关培训。
        
*   各团队业务负责人需能识别团队能胜任面试官角色的人，并且重视面试官选拔及标准化培养工作。
    

## 面试官提报

**提报流程：**++**各部门统一将推荐人选提报至团队HRBP处**++，由HRBP进行初步审核后，汇总提交至培训组，统一安排后续培养环节。

## 面试官上岗培训

*   由**培训组**根据提报名单统一规划及安排，**招聘团队**辅助实践指导并跟进学习效果回收；
    
*   **培训内容：**
    
    | **阶段** | **耗时** | **内容** | **阶段标记** | **备注** |
    | --- | --- | --- | --- | --- |
    | **0.选拔与提报** | —— | 由部门完成选拔及提报，纳入《面试官人才库》 | 预备面试官 | 学习计划未完成，暂时无法参与面试 |
    | **1.自学与测试** | 15-20分钟 | 1.  自学《面试官手册》学习<br>    <br>2.  完成《面试官认证测试》（100分合格） | 实习面试官 | 通过后开放面试权限，开始分派面试任务（未完成无法参与面试） |
    | **2.实践与评估** | 1-2小时 | 前1-2场面试需由招聘同事跟面，并评估面试表现（平均4分及以上合格）。 | 实习面试官 | 合格后可独立执行面试 |
    | **3.面授课程与正式认证** | 4-5小时 | 参与《金牌面试官》培训并通过课堂考核 | 认证面试官 | 标签授予，完成正式认证 |
    
    ## 面试官工作规范与考核要点
    
*   **面试官必须严格遵循《面试官手册》中的标准与流程，确保面试过程的专业性与公正性，并致力于提升候选人体验。**
    
*   公司将定期对在库面试官进行考核，**核心指标包括**：
    
    1.  面评填写质量：是否客观、详实，并与人才标准对齐。
        
    2.  候选人体验评分：面试流程的规范性及专业礼节。
        
    3.  新人试用期通过率：所面试录用人选的岗位匹配度与稳定性。
        
*   评估不合格的面试官将触发【补充学习计划】，情节严重者将**取消面试官资质（无法派发面试）**
