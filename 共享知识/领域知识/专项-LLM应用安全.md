# 专项-LLM应用安全

> 本文档基于 OWASP Top 10 for LLM Applications、Anthropic 工程博客、国内外 AI 安全标准（GB/T 45958-2025 等）及 AI 安全企业（上海AI实验室、昆仑芯等）的实际 JD 整理。

## OWASP Top 10 for LLM Applications

| 风险 | 描述 | 防护 |
|------|------|------|
| **Prompt Injection** | 用户输入诱导模型执行非预期指令 | 输入过滤、角色分离、输出审核、沙箱隔离 |
| **Insecure Output Handling** | 模型输出被直接执行或渲染 | 输出校验、内容安全过滤、不信任模型输出 |
| **Training Data Poisoning** | 训练数据被恶意篡改 | 数据来源验证、异常检测 |
| **Model Denial of Service** | 消耗模型资源的攻击 | 速率限制、输入长度限制 |
| **Sensitive Information Disclosure** | 模型泄露训练数据中的敏感信息 | 训练数据清洗、输出过滤、差分隐私 |
| **Excessive Agency** | 模型拥有过多自动化权限 | 最小权限、人工审核关键操作 |
| **Overreliance** | 过度信任模型输出 | 人工验证关键决策、置信度可视化 |

## Prompt Injection 详解

**直接注入**：用户在 prompt 中嵌入指令，覆盖 system prompt。

**间接注入**：恶意内容隐藏在模型处理的文档/网页/邮件中。

**防护层级**：
1. System prompt 加固：明确指令优先级
2. 输入过滤：检测并清理注入模式
3. 输出核验：审计模型输出是否偏离预期
4. 沙箱执行：模型调用的代码在隔离环境中运行
5. 权限最小化：Agent 可用工具和能力受限

## Agent 安全

Agent 场景引入额外风险层（对应 Managed Agents 架构）：

- **工具调用风险**：Agent 可执行代码、读写文件、发送请求 → 攻击面扩大
- **记忆污染**：攻击者通过对话向 Agent 持久记忆中注入恶意信息
- **多 Agent 串扰**：多 Agent 间通信可能被劫持
- **权限提升**：Agent 通过工具调用获得未预期的系统权限

对应 Managed Agents 架构的安全设计：
- 凭证不进 Sandbox（通过 Vault 代理）
- Sandbox 抽象为 `execute(name, input) -> string`，Harness 不直接执行代码
- Session 日志 append-only，不可篡改

## 内容安全与安全护栏

- **安全护栏 (Guardrails)**：输入护栏（检测越狱尝试）+ 输出护栏（检测违规内容）
- **越狱 (Jailbreak)**：通过角色扮演、渐进引导、多语言混淆、编码绕过等方式绕过安全限制
- **红队测试 (Red Teaming)**：系统性攻击模型以发现安全漏洞。人工红队更精准（成本高），自动红队覆盖广（用另一个 LLM 攻击目标模型）
- **安全评测基准**：HarmBench、AdvBench、Anthropic Safety Eval

## 国内 AI 安全标准与政策

- **GB/T 45958-2025**：人工智能计算平台安全框架（2026.2.1 实施），首次为 AI 安全独立成标准
- **《生成式人工智能服务管理暂行办法》**（2023.8.15 施行）：中国首个生成式 AI 监管法规，要求训练数据合法、生成内容合规、服务提供者承担安全责任
- **《人工智能法（草案）》**：立法推进中，类比 GDPR/欧盟 AI Act

## AI 安全岗位招聘趋势（2025-2026）

基于上海AI实验室、昆仑芯等企业 JD：

- **AI 安全产品经理**：聚焦大模型安全评测、安全策略设计
- **模型安全方向**：负责 LLM 内容安全能力构建，安全护栏、输入安全、输出安全
- **安全评测体系**：设计多维度的模型安全评测基准，涵盖攻击防御、越狱检测、有害内容识别
- 关键能力要求：理解 RL 训练流程、模型行为边界、自动评测方案设计

## 主流 AI 安全产品方向

| 方向 | 描述 | 代表场景 |
|------|------|---------|
| **AI 安全评测平台** | 对模型进行系统性安全测试 | 越狱检测、有害输出识别、对抗鲁棒性 |
| **内容审核 AI** | 用 AI 模型检测 UGC 违规内容 | 社交媒体、直播审核、敏感内容过滤 |
| **AI 生成内容标识** | 识别 AI 生成/深度伪造内容 | 深度伪造检测、AI 文本水印 |
| **模型安全护栏** | 部署在模型前后的安全过滤层 | 输入越狱检测 + 输出合规过滤 |
| **隐私保护 AI** | 训练和使用中保护数据隐私 | 联邦学习、差分隐私训练 |
