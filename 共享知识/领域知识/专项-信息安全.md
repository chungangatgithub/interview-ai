# 专项-信息安全

## 基础安全概念

### CIA 三要素

- **机密性 (Confidentiality)**：确保数据只能被授权方访问。技术手段：加密、访问控制、身份认证。
- **完整性 (Integrity)**：确保数据未被未授权篡改。技术手段：哈希校验、数字签名、审计日志。
- **可用性 (Availability)**：确保授权用户能在需要时访问系统。技术手段：冗余、负载均衡、DDoS 防护。

### 常见攻击类型

| 攻击类型 | 原理 | 防护思路 |
|---------|------|---------|
| SQL 注入 | 用户输入被拼接进 SQL 语句执行 | 参数化查询、ORM、输入校验 |
| XSS (跨站脚本) | 恶意脚本注入页面，在用户浏览器执行 | 输出编码、CSP、输入过滤 |
| CSRF (跨站请求伪造) | 诱导用户执行非本意操作 | CSRF Token、SameSite Cookie |
| SSRF (服务端请求伪造) | 诱导服务器发起非预期请求 | URL 白名单、内网隔离 |
| 命令注入 | 用户输入被拼接进系统命令执行 | 参数化、白名单校验、沙箱隔离 |

### 认证与授权

- **认证 (Authentication)**：确认你是谁。方式：密码、多因素认证(MFA)、OAuth、SSO、Passkey。
- **授权 (Authorization)**：确认你能做什么。模型：RBAC（基于角色）、ABAC（基于属性）、PBAC（基于策略）。
- **最小权限原则 (Least Privilege)**：每个主体只拥有完成其任务所必需的最小权限。

### 安全开发流程

- **SDL (安全开发生命周期)**：需求分析 → 威胁建模 → 安全设计 → 安全编码 → 安全测试 → 安全部署 → 安全运维。
- **威胁建模 (Threat Modeling)**：STRIDE 模型（Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege）。
- **安全编码规范**：OWASP Top 10、CWE Top 25。

### 数据安全

- **数据分类**：公开、内部、机密、绝密。
- **数据生命周期**：创建 → 存储 → 使用 → 共享 → 归档 → 销毁。
- **加密**：传输加密(TLS)、存储加密(AES)、端到端加密(E2EE)。
- **脱敏与匿名化**：数据脱敏、差分隐私、k-匿名性。
