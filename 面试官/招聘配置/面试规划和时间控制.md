# 面试规划和时间控制

---

## 面试流程与时间分配

| 阶段 | 流程 | 时长 |
|------|------|------|
| **开场** | 开场白与面试官自我介绍 | 1 分钟 |
| | 候选人自我介绍或关键经验询问 | 5 分钟 |
| **提问与倾听** | 专业能力评估（2-3 项） | 25 分钟 |
| | 素质能力评估（2-3 项） | 10 分钟 |
| | 简历疑点排查 | 5 分钟 |
| | 动机挖掘（离职和入职） | 5 分钟 |
| **结束** | 提供信息与答疑 | 3 分钟 |
| | 结束感谢 | 1 分钟 |
| **总计** | | **55 分钟** |

---

## 执行要点

### 1. 面试开场与基本了解

- 准时开始，友好问候，简要自我介绍
- 清晰说明面试流程、目的和时长
- 营造轻松、开放、平等的对话氛围，缓解候选人紧张情绪

### 2. 有效提问——结构化面试问题

- **专业能力评估**：针对预设的核心能力问题，聚焦行为事例，运用 STAR 原则（Situation 情景, Task 任务, Action 行动, Result 结果）进行深度提问，获取具体、完整的行为事例
- **素质能力评估**：将能力项转化成行为，再转化成问题，再通过使用 BEI 行为事件访谈法进行提问
- **深入追问 & 疑点排查**：对模糊、笼统的回答（如"我们团队合作得很好"）进行层层追问：
  - "你具体负责哪部分？"
  - "当时遇到了什么困难？"
  - "你采取了什么具体行动？"
  - "最终结果如何？"
- **真实动机挖掘**：包括离职动机（预判雇佣风险），入职动机（预判稳定性与文化适配）

### 3. 有效倾听与观察

- **积极倾听**：全神贯注，保持眼神交流，适时点头示意，鼓励候选人充分表达
- **礼貌回应**：不打断、不评论，用点头或简短回应鼓励表达
- **观察非语言信号**：
  - 肢体语言：是否放松、眼神交流、手势是否自然
  - 语言表达：逻辑性、条理性、是否夸大或回避问题
  - 情绪反应：面对压力或挑战性问题时的表现

### 4. 提供信息与答疑

- 清晰介绍公司、团队、岗位的具体情况和发展机会
- 真诚、专业地回答候选人提出的问题

### 5. 专业结束

- 感谢候选人的时间和分享
- 清晰告知后续流程步骤及预计反馈时间

### 6. 实时记录

- 在面试过程中或面试结束后立即记录关键回答、行为事例、观察到的细节及初步印象（避免依赖记忆）
- 请使用统一的面评模板

## 注意事项

### 面试礼仪

- 准时开始，准时结束
- 避免临时取消线下面试、线上面试要开摄像头
- 如果面试刚开始就发现不合适，也请尽可能保证面试流程的完整性
- 避免容易被误解为歧视的问题（如婚姻、宗教等）

### 控制节奏与时间

- 合理分配时间给不同问题，确保核心能力点得到充分考察
- 适时引导话题，避免过度发散

### 警惕面试目标跑偏

- 不要使用偏题怪题，或者纠缠于候选人未能正确作答的某个问题
- 面试不是吵架，不是为了压倒对方或者证明自己

### 不要被候选人牵着鼻子走

- 允许候选人提问，但始终记住面试主题，避免角色反转
- 有时间观念，礼貌地打断候选人

### 保持中立与客观

- 避免引导性问题或暗示期望答案
- 不要当场给出面试结论，或表现出明显倾向；禁止与候选人现场谈钱
- 对每位候选人使用相同核心问题框架，保证公平性

### 注意保密

- 不要泄露我司商业机密！避免被面试！避免被套取商业信息！
- 禁止询问或透露薪资等敏感信息（可跟候选人表达后续由招聘面试官统一沟通）
