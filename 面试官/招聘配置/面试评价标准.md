# 面试评价标准

**适用岗位**：以 `面试官/招聘配置/岗位信息.md` 中的「当前招聘岗位」为准  
**评分范围**：1-5 分  
**及格线**：3.0 分

---

## 一、AI 思维模式及深度评估

> 关注候选人 AI 潜力，是否具备 AI 能力和 AI 认知理解力。  
> 若该岗位不涉及 AI 评估，可整体跳过本节，评估说明填写"无"。

### 评价维度

| 维度 | 评分说明 | 关注点 |
|------|----------|--------|
| **1、AI 思维** | 是否具有 AI 思维模式，深度如何 | 候选人需理解 AI 的能力边界，明确了解什么适合用 AI 解决，什么不适合用 AI 解决 |
| **2、技术深度（AI 实践）** | 候选人工作中 AI 实践经验深度 | 候选人不仅使用过 AI 工具，更重要的是理解背后的原理，有实际的项目落地经验，能说清楚项目中的挑战和解决方案，并且能够准确评估和选择合适的 AI 技术 |
| **3、AI 知识储备** | 了解候选人的 AI 潜力以及在 AI 领域持续学习能力和洞察力 | 候选人是否对 AI 领域保持敏感度，了解最新进展（如新模型、新应用场景），是否有自己的学习渠道和社区参与经验，是否能够快速上手新的 AI 工具和框架 |
| **4、AI 工具应用** | 是否具有超级个体特质 | 能够利用 AI 工具实现 10x 的效率提升，具备独立完成端到端项目的能力，具有自己的 AI 工作流和最佳实践 |

### 评分标准

#### 1、AI 思维

| 分数 | 等级 | 描述 |
|------|------|------|
| 1 | 思维盲区 | 对 AI 的可能性缺乏感知 |
| 2 | 思维萌芽 | 被动接受 AI 工具的存在 |
| 3 | 思维解构 | 具备基本的 AI 重构意识 |
| 4 | 思维创新 | 以"AI 优先"的视角重新构想产品/业务形态 |
| 5 | 思维引领 | 具备战略级 AI 视野，并能推动团队 |

#### 2、技术深度（AI 实践）

| 分数 | 等级 | 描述 |
|------|------|------|
| 1 | 技术陌生者 | 不具备 AI 相关技术能力 |
| 2 | 技术入门者 | 了解基础编程和 AI 概念 |
| 3 | 技术实践者 | 具备独立完成 AI 功能模块的能力 |
| 4 | 技术深耕者 | 具备模型微调经验 |
| 5 | 技术引领者 | 能设计 AI 系统架构并能指导团队 |

#### 3、AI 知识储备

| 分数 | 等级 | 描述 |
|------|------|------|
| 1 | AI 小白 | 对 AI 基本概念不了解，无相关工具使用经验 |
| 2 | AI 认知者 | 了解 AI 基本术语，听说过主流 AI 工具，但未深入 |
| 3 | AI 熟悉者 | 熟悉主流 AI 工具和应用场景，能清晰描述 AI 的基本原理和局限性 |
| 4 | AI 深耕者 | 深入理解 AI 技术原理，掌握多种 AI 工具和框架，能进行技术选型建议 |
| 5 | AI 专家 | 具备 AI 领域的全面知识，能为团队或组织提供战略级技术指导 |

#### 4、AI 工具应用

| 分数 | 等级 | 描述 |
|------|------|------|
| 1 | 工具观望者 | 从未主动使用过任何 AI 工具 |
| 2 | 工具尝试者 | 偶尔使用常见 AI 工具 |
| 3 | 工具熟练者 | 熟练使用多种 AI 工具 |
| 4 | 工具整合者 | 能搭建自动化 AI 工作流 |
| 5 | 工具创造者 | 定制 AI 工具或开发 AI 原生应用 |

## 二、技术能力评价

> 请参照面试候选人的目标职级进行评价。如果候选人是初级，请用初级的标准看他是否独立；如果候选人是高级，请用高级的标准看他是否有架构能力。3 分代表"他就是我们要的这个级别的人"。

### 评价维度

| 维度 | 评分说明 | 关注点 |
|------|----------|--------|
| **1、技术深度**（对标目标职级） | 对核心技术的掌握程度，是否具备解决复杂问题的能力 | 重点关注候选人在特定技术领域的深入理解、实践经验以及解决高难度技术问题的能力 |
| **2、技术广度**（对标目标职级） | 对相关技术领域的了解程度，是否具备跨领域学习能力 | 评估候选人对多个技术领域的了解程度，是否已经学习和适应新技术 |
| **3、项目经验**（对标目标职级） | 参与项目的规模、复杂度，以及在项目中承担的角色和贡献，当前项目需求的匹配程度 | 重点关注候选人在大型或复杂项目中的实际经验，以及其在项目中的技术领导力或关键贡献，如实做描述 |

### 评分标准（统一适用于三个维度）

| 分数 | 描述 |
|------|------|
| 1 | 能力完全不匹配当前目标职级 |
| 2 | 能力未完全达到当前目标职级的要求 |
| 3 | 能力扎实匹配当前目标职级 |
| 4 | 能力高于当前目标职级的平均水平 |
| 5 | 能力显著超出当前目标职级的要求 |

### 各维度补充说明

#### 技术广度

| 分数 | 描述 |
|------|------|
| 1 | 技术广度严重不足 |
| 2 | 技术广度部分缺失 |
| 3 | 技术广度恰好匹配目标职级要求 |
| 4 | 技术广度高于目标职级平均水平 |
| 5 | 技术广度显著超出目标职级要求 |

#### 项目经验

| 分数 | 描述 |
|------|------|
| 1 | 项目经验严重不足 |
| 2 | 项目经验部分缺失 |
| 3 | 项目经验恰好匹配目标职级要求 |
| 4 | 项目经验高于目标职级平均水平 |
| 5 | 项目经验显著超出目标职级要求 |

## 三、通用能力与潜力评价

### 评价维度

| 维度 | 评分说明 |
|------|----------|
| **1、文化价值观匹配度** | 需要判断是否价值观匹配，在文化价值观中重点突出了哪一个价值观方向：真诚、热爱、专注、勇敢 |
| **2、学习敏锐度与技术好奇心** | 面对新知识、新技术、新环境时，快速吸收、理解、整合并应用到实践中的能力；对技术本质的探索欲，主动追踪前沿动态，乐于拆解黑盒，不满足于「知其然」，追求「知其所以然」的内在动力 |
| **3、逻辑思维与问题分析能力** | 在过往工作中能够采取科学有条理的逻辑方法，结构化的思维，与他人沟通，表达自我观点，思考分析问题逻辑清晰，具备合理规划工作的能力 |
| **4、主动性及自驱力** | 主动性强，能够较好的把思考的问题转化成落地实践，及时反馈。工作中能投入更多的精力、善于发现和创造新机会，并能自发、积极的采取行动、追求目标，而不是被外部压力或被动所驱使 |
| **5、系统性思维/架构意识**（潜力指标） | 将问题视为一个整体系统来思考的能力，在设计解决方案时，自觉考虑可扩展性、可维护性、性能、安全性、成本等非功能性需求，以及技术选型的长远影响 |
| **6、团队管理** | 是否具备团队管理能力，或是否具备团队合作精神，能够积极主动地参与团队工作。重点关注候选人在团队中的领导力、协作能力以及对团队目标的贡献 |
| **外部公司AI应用成熟度** | 了解其所在公司在AI技术应用方面的真实实践水平，以此作为窗口，洞察当前外部市场在AI应用上的战略方向、落地深度、技术路径及组织推动方式 |

### 评分标准

#### 1、文化价值观匹配度

| 分数 | 描述 |
|------|------|
| 1-5 | 根据候选人与公司核心价值观（真诚、热爱、专注、勇敢）的匹配程度综合评分 |

#### 2、学习敏锐度与技术好奇心

| 分数 | 描述 |
|------|------|
| 1 | 完全抵触学习新知识，技术栈陈旧，且不愿改进 |
| 2 | 学习被动，仅掌握已熟悉的技能 |
| 3 | 有持续学习的习惯，愿意尝试新事物，不排斥改变 |
| 4 | 主动学习新技术，并能快速应用到实际工作中 |
| 5 | 主动追踪前沿动态，并善于总结方法论，乐于分享和指导他人 |

#### 3、逻辑思维与问题分析能力

| 分数 | 描述 |
|------|------|
| 1 | 无法清晰定义问题，面对复杂情况完全不知所措 |
| 2 | 问题描述混乱，分析停留在表面 |
| 3 | 能够按照一定逻辑拆解问题，给出合理可行的解决方案 |
| 4 | 善于结构化分析问题，能多角度思考 |
| 5 | 思维极其清晰严密，能迅速抓住问题本质 |

#### 4、主动性及自驱力

| 分数 | 描述 |
|------|------|
| 1 | 工作完全被动 |
| 2 | 基本按指令行事，需要上级反复跟进 |
| 3 | 能按时保质完成分配的任务 |
| 4 | 经常主动承担额外责任，能预见潜在问题并提前行动 |
| 5 | 极强的主人翁意识，总是承担有挑战的任务，并驱动项目前进 |

#### 5、系统性思维/架构意识

| 分数 | 描述 |
|------|------|
| 1 | 完全不关心系统设计 |
| 2 | 只关注自己写的代码片段，很少考虑对系统整体的影响 |
| 3 | 理解自身模块与上下游的依赖，能完成局部设计，但整体架构把控需指导 |
| 4 | 能清晰把握模块间交互关系，考虑到未来变化，有一定的重构和优化意识 |
| 5 | 具备全局视野，能从整个系统角度设计模块，考虑扩展性、可维护性、性能及技术演进 |

#### 6、团队管理（不评分，仅文字描述）

> 根据候选人的领导力、协作能力及对团队目标的贡献进行文字描述（视岗位级别侧重考察），无需打分。

#### 外部公司AI应用成熟度（不评分，仅文字描述）

> 根据候选人过往公司在AI战略、落地场景、量化效果、技术深度及推广情况进行文字描述，无需打分。

### 岗位关键素质权重建议

| 素质 | 权重 | 说明 |
|------|------|------|
| 学习敏锐度与技术好奇心 | 高 | AI 领域快速迭代，学习力与好奇心关键 |
| 逻辑思维与问题分析能力 | 高 | 架构设计需要结构化思维 |
| 系统性思维/架构意识 | 高 | 衡量技术潜力与成长天花板 |
| 主动性及自驱力 | 中 | 自驱力影响成长速度 |
| 文化价值观 | 基础 | 一票否决项 |
| 团队管理 | 视级别 | 高级别岗位重点考察 |

## 四、面试定级与综合评价

> AI Native + 综合技术能力 + 通用能力与潜力整体评估

### 面试定级标准

| 定级 | 描述 |
|------|------|
| **专家** | 在行业内具有影响力，能制定技术战略，推动技术变革 |
| **资深** | 在某一领域有深度积累，能规划技术方向，能做出关键技术决策 |
| **高级** | 具备技术判断力，能评估技术选型的利弊，开始指导初中级工程师成长 |
| **中级** | 能独立负责功能模块 |
| **初级** | 需在指导下完成具体任务 |

### 评价维度（必填）

| 维度 | 评价说明 |
|------|----------|
| **面试定级** | 根据 AI 能力、技术能力、通用能力与潜力的综合表现，从专家/资深/高级/中级/初级中选择对应定级 |
| **优势** | 描述候选人在技术能力、项目经验、综合素质（如逻辑思维与问题解决、沟通与协作、学习能力与好奇心、抗压能力等）方面的突出表现 |
| **不足** | 客观指出候选人在技术能力、项目经验或综合素质方面存在的短板或提升空间，需结合目标职级进行合理评判 |
| **匹配度** | 评估候选人与应聘职位的匹配程度，从技术能力、项目经验、自我定位与职位需求的契合度进行综合判断 |
| **推荐意见** | 根据整体评估，给出明确的录用建议 |

### 匹配度判断标准

| 匹配度 | 描述 |
|--------|------|
| **高度匹配** | 能力远超职位要求，可胜任更复杂的工作，建议优先录用 |
| **比较匹配** | 能力基本符合职位要求，虽有少量短板但可通过培养弥补，建议录用 |
| **一般匹配** | 部分能力符合要求，但核心技能或经验有明显缺失，需慎重考虑或降级录用 |
| **不匹配** | 能力与职位要求差距较大，不建议录用 |

### 推荐意见判断标准

| 推荐意见 | 描述 |
|----------|------|
| **强烈推荐** | 表现远超预期，建议优先录用 |
| **推荐** | 表现符合预期，建议录用 |
| **待定** | 有亮点但存在明显风险，需横向对比其他候选人或补充面试 |
| **不推荐** | 表现未达预期，不建议录用 |

## 六、注意事项

### 评分原则

1. **对标职级**：始终参照候选人的目标职级进行评价，3 分代表"恰好匹配该级别"
2. **客观公正**：基于事实和表现评分，避免主观偏见
3. **统一标准**：对所有候选人使用相同评分标准
4. **证据支撑**：评分需有具体事例或表现作为依据
5. **岗位导向**：以岗位需求为核心评估匹配度
6. **整数评分**：单项评分使用整数（1-5），不使用小数
7. **推荐意见简洁**：推荐意见只需给出选项结果（强烈推荐/推荐/待定/不推荐），无需附加说明

### 常见问题

| 问题 | 处理方式 |
|------|----------|
| 候选人背景与岗位不完全匹配 | 重点评估可迁移能力和学习潜力 |
| 技术能力强但软素质弱 | 分开评估，在综合评价中权衡 |
| 候选人过度包装简历 | 通过追问验证实际深度 |
| 面试时间不足以全面评估 | 聚焦核心能力，记录待验证项 |
| 岗位不涉及 AI 评估 | AI 评估部分整体跳过，评估说明填写"无" |

### 红旗信号（一票否决）

- 价值观严重不匹配
- 诚信问题（简历造假、回答不诚实）
- 明显的沟通障碍
- 对技术毫无热情
- 频繁短期离职且无合理解释
